# Stitch Tasarim Sistemi Ozeti

## Proje

- Ad: Gold Banyo Web Temasi
- Project ID: `13800263520330366969`
- Kaynak: Stitch MCP
- Ana hedef: Gold Banyo ziyaretci sitesi frontend tema sistemi

## MCP'de Gorulen Ana Tasarim Sistemleri

### Aurelian Onyx

- Kullanim: Gece/koyu frontend varyanti.
- Fontlar: Playfair Display + Space Grotesk.
- Renk dili: onyx/siyah, charcoal yuzeyler, altin vurgu, frosted glass.
- Etki dili: glassmorphism, glow border, yavas/dramatik gecisler.
- Layout: 1440px container, 12 kolon, genis nefes alan luxury e-commerce grid.

### Gold Banyo / Onyx Architectural

- Kullanim: Gündüz/gece ailesini birlikte tarif eden ana sistem.
- Font: Overpass.
- Gündüz: ivory, parchment, warm white, soft beige, siyah/altin CTA.
- Gece: deep matte black, brushed gold, high contrast.
- Stil: architectural high-contrast, editorial spacing, 1px border, shadow yerine tonal layer.

## Kritik Kural

Stitch temalari sadece frontend/site temalaridir. Admin panelin kendi dinamik tema sistemi vardir; `AdminTema` alani ve admin CSS yapisi bozulmayacak.
