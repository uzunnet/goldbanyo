## 4. Faz 1 — İçerik + Dil (ÖNCELİK)

### 4A. İçeriği doldur (seed)
- `UpdateDb` projesini kullan (AGENTS.md §9 EF Migration dışı DB değişikliği yasak — seed kod ile).
- `DesadoorDbContext.cs:213-227` `UrunAilesi`+`Urun` seed'ini gerçek/temsilî veriyle aç (DateTime sabit literal kalsın — migration uyumu).
- Eksik seed setleri ekle: RAL renkleri, malzemeler, kaplamalar, sayfa içerikleri (anasayfa hero/kategori/istatistik, hakkımızda, iletişim, blog, sss, projeler, referanslar), menü (`api/menu/desadoor` + footer).
- Yeni migration üret + uygula; **migration öncesi DB yedeği** (`Yedekler/db/`, AGENTS.md §20).
- Doğrula: Faz 0 hattı ile her public sayfa artık dolu mu.

### 4B. Çeviri verisini doldur
- `api/dil/ceviriler/{tr,en}` kaynağını (DB + FusionCache, AGENTS.md §19 — json kaynak değil) tam anahtar setiyle seed et.
- `.razor` dosyalarındaki hardcoded Türkçe metinleri `dil.T("anahtar","Varsayılan")` ile değiştir — en çok kullanılan public sayfalardan başla.

### 4C. Dil değişimini sayfa yenilemeden çalışır yap (asıl düzeltme)
- `DilServisi`'ne değişiklik bildirimi ekle: `event Action? DilDegisti;` → `DilDegistirAsync` sonunda `DilDegisti?.Invoke()` (`DilServisi.cs:46-51`).
- Çeviri kullanan bileşen/sayfalar (layout + public sayfalar) `OnInitialized`'da event'e abone olup `InvokeAsync(StateHasChanged)`, `Dispose`'da abonelikten çık.
- `DesaDoorDuzen.razor.cs:305` `nav.NavigateTo(nav.Uri, forceLoad:false)` satırını **kaldır** (no-op).
- Sonuç: dil değişince **tek sayfa yenilenmeden** tüm metinler güncellenir.

## 5. Faz 2 — Performans

- **CSS birleştir**: `index.html:21-40` ~20 dosya → build-time tek bundle (sıra korunarak).
- **Font**: Google Fonts'u `media="print" onload` / `preload` ile non-blocking yap veya self-host.
- **WASM**: `<BlazorEnableCompression>` + AOT/trim değerlendir.
- **Cache**: menü/çeviri/sayfa-içeriği için UI tarafında basit in-memory cache; dil değişiminde menüyü gereksiz çekme.
- **Lazy**: 3D (`uc-boyut-motoru.js`, Three.js) yalnız ürün detay rotasında yüklensin.
- AGENTS.md §8 / `08_Performans_Cache_Render.md`.
